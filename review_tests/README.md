# review_tests — isolated reproductions and tools

Nothing here modifies the supplied bundle. Every script takes the **bundle root** (the extracted `Sheep_Claude_Review_2026-10-01` folder) as its first argument, builds/extracts what it needs into a temporary directory and removes it afterwards. Requirements: Python ≥ 3.11, `g++` (C++17), `pip install cryptography pyserial`.

| Path | What it proves | Result on 2026-10-01 |
|---|---|---|
| `csvstore_crash/run_crash_matrix.py` | the **real** `CsvStore.h` (host build, only the mount path rewritten) keeps every ACKed batch exactly once across a crash before each of 399 mutating syscalls × {clean, torn write}; `FIRST_BOOT_FIX=1` applies the proposed one-line patch to the *host copy only* | 794/798 pass, 4 first-boot halts (F10); with fix 798/798 |
| `ble_assembly/run_fuzz.py [mutate]` | the **real** `Collar::handleNotify()` (extracted verbatim) equals a reference protocol model on 200 000 fuzzed fragment streams; `mutate` proves the harness catches a broken assembler | 0 wrong accepts / 0 missed; mutant: 11 945 wrong accepts |
| `server/repro_busy_slot_dos.py` | an unauthenticated TLS client denies upload service (F7) | reproduced |
| `capacity/capacity_model.py` | capture/storage/upload/backlog arithmetic; synthetic compression; server validation time | see REVIEW §5.7 |
| `capacity/binary_to_csv_roundtrip.py` | CSV can be regenerated byte-exactly from packed 617-byte batches (real `CsvStore` output) and `%.2f` of all 65 536 gyro values matches C printf (host libc only) | PASS |
| `evidence/evidence_analysis.py` | re-derives every number quoted from logs 01/08/09/11 | see REVIEW §4–5 |
| `tools/csv_continuity_check.py` (+ `test_…`) | hardware-test helper: duplicate/partial/gap/regression audit of hourly CSVs | self-test PASS |
| `tools/serial_timestamp_logger.py` (+ `test_…`) | host-UTC-stamped serial capture with scheduled commands | self-test PASS over a pty |
| `tools/vm_ss_sampler.sh` | read-only 1 Hz TCP-internals sampler for the VM | syntax-checked only (no `ss` in the review sandbox) |

`./run_all.sh <bundle_root>` runs everything above plus the bundle's own `work/test_hourly_server.py`.

**Limits.** Host tests validate logic against POSIX semantics and a stated crash model; they say nothing about BLE/Wi-Fi radio behaviour, FAT/SD power-loss behaviour, ESP32 newlib float printing, memory, or throughput on the device. See HARDWARE_TEST_PLAN.md.
